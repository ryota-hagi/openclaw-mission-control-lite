# OpenClaw Mission Control (Lite)

OpenClawを運用するための **超軽量・静的HTMLダッシュボード** です。

- タスクボード（Todo / In Progress / Done）
- cron一覧（手動管理）
- 実行ログ（手動貼り付け）
- ローカルストレージ保存
- JSONエクスポート/インポート

## 重要（機密情報）
- このリポジトリは **Public** で GitHub Pages 公開されます。
- **顧客名・案件名・個人情報・社内の具体ログ** を平文で入れないでください。
- seed（初期データ）はデモ用にしてあります。

## 使い方
1. GitHub Pages のURLを開く
2. タスクを追加
3. 矢印でステータス移動
4. 必要ならJSONエクスポートでバックアップ

## Development
単なる静的ファイルなので、編集してpushするだけで反映されます。
